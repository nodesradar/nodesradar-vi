## Câu hỏi thường gặp

**Free Nodes Radar là gì?**

**Tôi nên dùng link đăng ký nào?**

Dùng link Clash cho Clash Verge Rev, Clash Party, FlClash, Clash Meta for Android và Stash; link V2Ray cho v2rayN, v2rayNG, Shadowrocket, NekoBox, Hiddify và Karing; link sing-box cho các ứng dụng sing-box chính thức.

**Làm sao để thêm link đăng ký?**
